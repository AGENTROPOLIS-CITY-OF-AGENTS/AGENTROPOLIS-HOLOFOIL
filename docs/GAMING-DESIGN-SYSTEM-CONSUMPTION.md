# Gaming District Design System Consumption — HOLOFOIL

## Relationship

HOLOFOIL consumes the AGENTROPOLIS Gaming District Design System for all game-facing collectible experiences.

Inheritance:

AGENTROPOLIS Design System
-> Gaming District Design System
-> HOLOFOIL material/presentation layer

## Gaming supplies

- game/world identity
- faction identity
- rarity semantics
- progression context
- playable/unlockable state
- game receipt references
- game hierarchy
- encounter/event provenance

## HOLOFOIL supplies

- deterministic holographic/foil material
- refraction
- card/presentation shell
- 3D exhibition
- material presets
- reduced-motion rendering
- export-ready visual configuration

## Non-ownership rule

HOLOFOIL does not own:
- gameplay logic
- player balances
- mission settlement
- game authority
- game registry
- cross-game progression
- IP authority

Game-facing Holofoil presentation follows committed Gaming District truth.

## Visual composition

A game collectible may combine:

- Gaming identity plate
- Holofoil material
- rarity/frame treatment
- faction/world mark
- playable/unlockable state
- receipt/provenance affordance

Cyan/red semantic status remains inherited from the Agentropolis Design System.

## ARCANA54 cross-consumption

If the collectible is also a story-world object, ARCANA54 may provide authorized story/lore metadata.

ARCANA54 does not override Gaming state.
HOLOFOIL does not override ARCANA54 story canon.
IP authority remains external to both.
