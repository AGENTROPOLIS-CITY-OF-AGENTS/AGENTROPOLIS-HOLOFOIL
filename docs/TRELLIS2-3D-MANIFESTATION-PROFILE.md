# TRELLIS.2 3D Manifestation Profile

Status: production-integration candidate.

HOLOFOIL may consume approved 3D asset derivatives produced through Creator/TRELLIS.2, but it remains presentation and collectible manifestation authority only.

## Corridor

```text
Creator rights-cleared source
-> TRELLIS.2 generated master candidate
-> cleanup / retopo / rigging / optimization
-> canonical entity + provenance binding
-> HOLOFOIL material/collectible manifestation
-> PARALLAX spatial verification when scene-bound
-> VERITY independent review
-> game/runtime consumption
```

## Stable identity

The same collectible/entity may have multiple representations:

- archival 3D master
- game-runtime GLB
- mobile LOD
- web/spatial derivative
- card render
- animated reveal

These representations do not create a new gameplay identity when canonical entity id, project id, authoritative gameplay reference, and lineage remain stable.

## Required 3D manifestation fields

Every generated 3D manifestation should carry:

- canonicalEntityId
- projectId
- sourceAssetId(s)
- sourceRightsReceipt(s)
- generator/provider profile
- generator job/receipt id when executed
- masterAssetHash
- runtimeDerivativeHash
- triangle counts by LOD
- texture profile
- material profile
- target runtime/device tier
- optimization receipt
- spatial verification receipt when applicable
- independent VERITY review receipt before production promotion

## Authority locks

HOLOFOIL does not determine:

- rarity
- ownership
- deck legality
- gameplay outcome
- economy
- mint authority
- wallet signing
- treasury operations
- token issuance
- IP rights

It renders committed, authorized state.

## BLOCKBANGERS

BLOCKBANGERS hero characters, DJ RED FANG, HOOD JUNKIE, lowriders, arcade props, and city modules may use this lane.

Game-facing derivatives should follow Gaming District performance budgets. The archival master is never destructively replaced by the game-optimized derivative.

**Generated != Verified != Authorized != Production.**
