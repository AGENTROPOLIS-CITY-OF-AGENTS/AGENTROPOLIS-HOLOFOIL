# HOLOFOIL Game Integration Checklist

Use this checklist for every new game.

## 1. Locate
- [ ] game repository verified
- [ ] authoritative rules/state source identified
- [ ] canonical entity schema identified
- [ ] rights/IP authority identified
- [ ] economy/reward/ranking authorities identified

## 2. Bind
- [ ] AGENTIC-ENTITY id mapping defined
- [ ] project/game id mapping defined
- [ ] HOLOFOIL material binding defined
- [ ] provenance/lineage references defined
- [ ] no duplicate collectible identity introduced

## 3. Validate
- [ ] authoritative committed state only
- [ ] hidden state cannot leak
- [ ] deterministic presentation verified
- [ ] reduced-motion/mobile fallback verified
- [ ] rights/provenance valid
- [ ] no implicit financial capability

## 4. Evidence
- [ ] game-specific metrics declared
- [ ] thresholds declared
- [ ] sample sizes declared
- [ ] deterministic/reproducible tests executed where applicable
- [ ] adversarial boundary tests executed
- [ ] economic boundary tests executed

## 5. VERITY
- [ ] independent reviewer used
- [ ] evidence math verified
- [ ] authority boundaries verified
- [ ] identity continuity verified
- [ ] rollback path verified

## 6. Promotion
- [ ] DARK
- [ ] CANARY
- [ ] VERIFIED_CANARY
- [ ] PRODUCTION

No stage may be skipped without a governed exception receipt.

## 7. Receipts
- [ ] integration
- [ ] identity binding
- [ ] simulation/evidence
- [ ] VERITY
- [ ] canary
- [ ] production
- [ ] rollback if used
