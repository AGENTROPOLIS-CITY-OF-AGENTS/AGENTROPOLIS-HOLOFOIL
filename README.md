# AGENTROPOLIS HOLOFOIL

Deterministic holographic and foil presentation for governed digital collectibles.

Holofoil is the **collectible manifestation system**. It does not own the underlying IP authority.

## Canonical boundary

- **AGENTROPOLIS Public IP District** owns IP identity, chain of title, rights scopes, licenses, adaptation authority, IP Equity Engine, filing workflows, portfolio lifecycle, watch/renewal state, and jurisdictional protection routes.
- **Holofoil** consumes IP Authority Receipts and manifests authorized properties/outputs as collectible editions.
- **ARCANA54** may invoke Holofoil when an authorized story object becomes collectible.
- **CHOAS GAMING PRODUCTIONS (GDP)** may produce authorized game/interactive/media outputs that later become Holofoil manifestations.

Token, collectible, or membership ownership never silently becomes copyright ownership, equity, revenue participation, or commercial rights.

Before manifestation, Holofoil should resolve authority through `ATG:IP` and fail closed when rights are missing, disputed, expired, outside scope, or awaiting required approval.

See the canonical consumption contract in:

`AGENTROPOLIS-CITY-OF-AGENTS/AGENTROPOLIS-PUBLIC-IP-DISTRICT/docs/HOLOFOIL-CONSUMPTION.md`

## NTRU / NTRUtv boundary
