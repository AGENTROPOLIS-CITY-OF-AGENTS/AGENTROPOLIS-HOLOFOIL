# AGENTROPOLIS HOLOFOIL

Deterministic holographic and foil presentation for digital collectibles.

Holofoil is not an NFT collection, blockchain protocol, minting application, security layer, or ARCANA-54 replacement.

```
Origin Engine approved asset
  → Holofoil material configuration
  → rendered collectible
  → optional ARCANA-54 spatial placement
```

AGENTROPOLIS-54T owns security. Holofoil never mints, signs wallets, deploys contracts, or bills generation.

## Surfaces

- **Overview** — product landing, specimen card, system relationships
- **Material Lab** — foil type, intensity, refraction, glow, opacity, grain, fresnel, light, pointer, tilt, animation, reset, export
- **Card Studio** — procedural sprites, pixel editor, trading-card foil wrap, metadata/pack export
- **Creature-Dex** — twelve original specimens as foil presentation records
- **3D Stage** — convention pavilions as material rooms (serialized vault replaces the retired inscription booth)
- **Storyboard** — local deterministic reveal beats
- **SDK / Integration** — typed adapter contracts

## Material schema

`agentropolis.holofoil.material.v1`

Foil types: holographic, chromatic, prism, neon-glitch, brushed-foil, rainbow-diffraction, serialized-collectible, museum-glass, obsidian-foil, custom.

Export is canonical JSON another Agentropolis application can consume.
